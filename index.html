Is There a Doctor On The Plane??

Gameplay Programmer / VR Developer

Unreal Engine 5 • C++ • Blueprints • OpenXR

About the Project

Is There a Doctor On The Plane?? is a virtual reality medical simulation set aboard a commercial aircraft. The player responds to an in-flight medical emergency by gathering information, assessing the patient, making clinical decisions, and performing interactive medical procedures.

The project combines medical simulation with traditional gameplay systems such as branching conversations, interactive objectives, NPC behavior, scoring, and player feedback.

Technical Highlights

  • Reusable branching conversation system
  • VR object interaction and procedure mechanics
  • Interactive AED and patient assessment systems
  • C++ parent classes with Blueprint configuration
  • NPC navigation and behavior
  • Persistent graphics and audio settings
  • Gameplay outcome and feedback systems

Technical Spotlights

Branching Conversation System

Built a reusable dialogue system for multi-tier patient and NPC interactions, including branching choices, outcome changes, gameplay actions, and conversation state.

VR Medical Procedures

Developed interactive procedure mechanics using VR grabbing, collision detection, target validation, feedback states, and progression logic for physical exam and AED interactions.

C++ / Blueprint Architecture

Created reusable C++ base classes for core gameplay behavior while exposing configuration to Blueprint children for rapid iteration on NPCs, widgets, and procedure content.

BACKGROUND

From Medicine to Game Development

I now focus on C++, Unreal Engine, VR, gameplay systems, and simulation, with a particular interest in projects where strong game mechanics can support training, education, or meaningful player experiences.
